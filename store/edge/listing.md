## Privacy

Single purpose description:

Saves, restores and backs up the user's tabs and windows.

tabs justification:

Read tab URLs and titles to save them, and open them to restore.

tabGroups justification:

Keep tab group names and colours in saved sessions.

storage justification:

Store sessions and backups locally.

unlimitedStorage justification:

Large sessions with hundreds of tabs exceed the default quota.

alarms justification:

Run the timed backup while the extension is idle.

favicon justification:

Show site icons in the session list from the browser's icon cache.

Host permission justification (https://api.gumroad.com/*):

Verify a Pro licence key the user enters; nothing else is sent.

Remote code: No
Does this extension collect personal information / user data: No
